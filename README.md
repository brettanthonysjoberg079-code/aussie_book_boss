# Aussie Book Boss 📚

**Your Elite AI eBook Market Research & Design Intelligence Agent**

Aussie Book Boss is a cutting-edge AI agent engineered for digital publishers, indie authors, and publishing entrepreneurs who demand actionable market intelligence and premium book design guidance. Powered by Google Gemini 3.5 Flash and deployed on Hugging Face Spaces, this agent combines deep market research, SEO optimization, and design mastery to identify future bestselling trends before they hit mainstream consciousness.

## 🎯 Core Capabilities

### 1. **Niche Discovery Engine**
Identifies high-velocity, under-saturated niches across Amazon KDP, Kindle Direct Publishing, and emerging digital markets. Analyzes category trends, competition density, and profit margins with surgical precision.

### 2. **Keyword/SEO Matrix Architecture**
Generates structured keyword research including:
- **Primary Keywords**: Core market-defining terms
- **7 Long-tail Keywords**: High-intent, lower-competition phrases
- **7 KDP Backend Phrases**: Amazon algorithmic optimization strings

### 3. **Blue Ocean Book Methodology**
Proprietary bestseller formulas combining psychological triggers with keyword integration:
- Punchy Title/Subtitle structures
- Emotional resonance optimization
- Market differentiation positioning

### 4. **Book Cover Design Intelligence**
Provides meticulous design briefs including:
- **Typography Specifications**: Font families, weights, hierarchy
- **Micro-contrast Rules**: Visual hierarchy and readability
- **3-Color Psychological Palettes**: Emotion-driven color theory
- **Thumbnail Optimization**: Mobile-first scaling guidelines

## 🚀 Quick Start

1. **Environment Setup**: Requires `GEMINI_API_KEY` environment variable
2. **Launch**: Deployed as a Gradio interface on Hugging Face Spaces
3. **Chat**: Interact conversationally with real-time streaming responses
